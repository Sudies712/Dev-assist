# 开发技术要点与踩坑

> 本文档收纳项目开发过程中沉淀的技术栈适配要点、架构决策细则与前端踩坑，供后续开发/维护时按需查阅。CLAUDE.md 仅保留索引。

## 一、技术栈要点（Spring Boot 4 适配，别踩坑）

- **Spring Boot 4.1.0**（很新，生态适配需确认版本）
- **Sa-Token** `spring-boot4-starter` @1.45.0（非 boot3）；密码哈希用 spring-security-crypto 的 `BCryptPasswordEncoder`（Sa-Token 内置 BCrypt 已弃用）
- **MyBatis-Plus** 3.5.17 `spring-boot4-starter` + `mybatis-plus-jsqlparser`（3.5.9+ 拆分了 jsqlparser，需单独引入）
- **API 文档**用 springdoc-openapi（Knife4j 不适配 SB4）
- **AOP** 用 `org.aspectj:aspectjweaver`（SB4 BOM 不管理 spring-boot-starter-aop）
- **jsqlparser 4.6** 包路径变化：`Column` 在 schema 包、`Alias` 在 expression 包、`ExpressionList` 不带括号
- **BaseEntity 不含 @Version**：可并发实体（Project/Requirement/Sprint/Task/Bug）单独加 @Version 乐观锁

## 二、架构决策细则

- **@DataScope 数据隔离**：注解 + Aspect + MultiDataPermissionHandler；用 **OR 链**（非 IN）拼 `project_id`；非成员见空集；`getSqlSegment` 开头必须 clear ThreadLocal（防递归栈溢出）。project 表手动过滤（无 project_id 列）
- **状态机**：枚举带 `next()` 方法，Service 用 `current.next().contains(target)` 校验，非法流转抛 50004
- **权限**：4 系统角色 + 权限码 `模块:操作`；ADMIN 不参与项目业务；写操作 `ensureMember` 校验
- **枚举存英文码**（PENDING_REVIEW 等），统一响应 `{code, message, data}`

## 三、前端踩坑

1. **文件上传必须用原生 fetch 直传**：项目 http(axios) 封装默认 `Content-Type: application/json`，会把 FormData 当普通对象 JSON 序列化成 `{"file":{}}`。见 `api/devassist/bug.ts`、`document.ts`、`user.ts` 的 `uploadXxx` 模式（构造 FormData + 手动带 `Authorization` + fetch 直传）
2. **下载用 `content-disposition` 判成败**：后端对 .txt 推断成 application/json，不能用 content-type 判断；`content-disposition` 存在即为文件，否则按错误 JSON 提示
3. **AI 类请求必须单独传 `timeout: 60000`**：`kb/ask`、`ai/*` 调 DeepSeek 冷启动常 >10s，http 默认 timeout:10000 会 ERR_ABORTED
4. **AI 任务草稿 confirm 落表后端要 sprintId**：前端建草稿时须给 TASK 项注入归属迭代（见 `views/devassist/ai/index.vue` handleCreateDrafts + draftSprintId 选择器）
5. **`.vue` 文件不支持 JSX**：cellRenderer 用 JSX 会编译失败（模块 500）。需 JSX 的列定义放 `.tsx`（hook）或改用表格 slot
6. **系统管理是 ADMIN 专属**：路由 `meta.roles: ["ADMIN"]`
7. **验证时勿反复登录同账号**：反复 curl 登录会覆盖 Redis 里按 userId 存的 refreshToken（`is-share: false`），导致浏览器旧 refreshToken 续期失败 401。验证登录应复用同一 token
8. **认证体系**：双 token（accessToken 2h + refreshToken 免登录可配 N 天）；前端 http 拦截器已实现本地 expires 预刷新 + HTTP 401 兜底刷新；登录/刷新接口在请求白名单
9. **系统配置齿轮仅 admin 可见**：lay-navbar 的 `isAdmin` 判断；页签持久化开关在系统设置面板，配置经 responsiveStorage 持久化
10. **顶部栏头像链路**：登录（getLogin 取 `user.avatar`）→ localStorage → store；上传头像后需同步 store + localStorage（`syncUserCache` 模式），否则刷新回退默认图
